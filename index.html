I Nguyên hàm cơ bản — Basic Antiderivatives

Hàm số \(F(x)\) là nguyên hàm của \(f(x)\) trên \(K\) nếu \(F'(x) = f(x)\) với mọi \(x \in K\).

\(F(x)\) is an antiderivative of \(f(x)\) if \(F'(x) = f(x)\).

\(\displaystyle\int x^n\, dx = \dfrac{x^{n+1}}{n+1} + C \ (n \neq -1)\)    \(\displaystyle\int \dfrac{1}{x}\, dx = \ln|x| + C\)
\(\displaystyle\int e^x\, dx = e^x + C\)    \(\displaystyle\int a^x\, dx = \dfrac{a^x}{\ln a} + C\)
\(\displaystyle\int \sin x\, dx = -\cos x + C\)    \(\displaystyle\int \cos x\, dx = \sin x + C\)
\(\displaystyle\int k\, dx = kx + C\)    \(\displaystyle\int \dfrac{1}{\cos^2 x}\, dx = \tan x + C\)

Ghi nhớ: \(C\) là hằng số tích phân (constant of integration).

Ví dụ (Example): \(\displaystyle\int (3x^2 + 2x + 1)\, dx = x^3 + x^2 + x + C\)

II Tính chất nguyên hàm — Properties

\(\displaystyle\int [f(x) \pm g(x)]\, dx = \int f(x)\, dx \pm \int g(x)\, dx\)
\(\displaystyle\int k \cdot f(x)\, dx = k \int f(x)\, dx\)    (với \(k\) là hằng số)
\(\displaystyle\left(\int f(x)\, dx\right)' = f(x)\)

Linearity: integral of sum = sum of integrals; constant factor can be pulled out.

III Tích phân xác định & Newton–Leibniz

Nếu \(F\) là một nguyên hàm của \(f\) trên \([a; b]\), thì:

\(\displaystyle\int_a^b f(x)\, dx = F(b) - F(a) = \left. F(x) \right|_a^b\)

The Fundamental Theorem of Calculus: definite integral equals \(F(b) - F(a)\).

Tính chất (Properties):

  • \(\displaystyle\int_a^a f(x)\, dx = 0\)
  • \(\displaystyle\int_a^b f = -\int_b^a f\)
  • \(\displaystyle\int_a^b f = \int_a^c f + \int_c^b f\)
  • \(\displaystyle\int_a^b k\, dx = k(b-a)\)
Ví dụ (Example): \(\displaystyle\int_0^2 (2x+1)\, dx = \left[x^2 + x\right]_0^2 = (4+2)-(0+0) = 6\)

IV Phương pháp tính tích phân — Techniques of Integration

1. Đổi biến (Substitution):

\(\displaystyle\int f(g(x)) \cdot g'(x)\, dx = \int f(u)\, du = F(g(x)) + C\)
Ví dụ: \(\displaystyle\int 2x e^{x^2}\, dx\). Đặt \(u = x^2\), \(du = 2x\, dx\) → \(= e^{x^2} + C\).

2. Từng phần (Integration by parts):

\(\displaystyle\int u\, dv = uv - \int v\, du\)
Ví dụ: \(\displaystyle\int x e^x\, dx = x e^x - e^x + C\) (đặt \(u=x\), \(dv=e^x\,dx\)).

Quy tắc chọn u (LIATE): Logarithm, Inverse trig, Algebraic, Trigonometric, Exponential.

V Diện tích hình phẳng — Area Under Curve

Diện tích dưới đồ thị: \(S = \displaystyle\int_a^b |f(x)|\, dx\)
Diện tích giữa hai đồ thị: \(S = \displaystyle\int_a^b |f(x) - g(x)|\, dx\)
Ví dụ: Diện tích giữa \(y = x\) và \(y = x^2\) trên \([0,1]\):
\(S = \displaystyle\int_0^1 (x - x^2)\, dx = \left[\dfrac{x^2}{2} - \dfrac{x^3}{3}\right]_0^1 = \dfrac{1}{2} - \dfrac{1}{3} = \dfrac{1}{6}\)

VI Thể tích vật thể tròn xoay — Volume of Revolution

Quay quanh trục Ox: \(V = \pi \displaystyle\int_a^b [f(x)]^2\, dx\)
Quay quanh trục Oy (phụ): \(V = \pi \displaystyle\int_c^d [g(y)]^2\, dy\)
Ví dụ: Quay \(y = x\) quanh Ox, \(x \in [0, 2]\):
\(V = \pi \displaystyle\int_0^2 x^2\, dx = \pi \left[\dfrac{x^3}{3}\right]_0^2 = \dfrac{8\pi}{3}\)

Thể tích hình cầu: Quay \(y = \sqrt{r^2 - x^2}\) trên \([-r, r]\) quanh Ox → \(V = \dfrac{4}{3}\pi r^3\).

VII Ứng dụng thực tế — Real-World Applications

Đại lượngCông thức tích phân
Quãng đường (displacement)\(s = \displaystyle\int_{t_1}^{t_2} v(t)\, dt\)
Tổng quãng đường (total distance)\(d = \displaystyle\int_{t_1}^{t_2} |v(t)|\, dt\)
Gia tốc → vận tốc\(v(t) = v(0) + \displaystyle\int_0^t a(\tau)\, d\tau\)
Tổng chi phí (total cost)\(C(x) = C(0) + \displaystyle\int_0^x MC(u)\, du\)
Lợi nhuận\(P = \displaystyle\int_0^q (MR - MC)\, dx\)
Thặng dư tiêu dùng\(CS = \displaystyle\int_0^q [D(x) - p]\, dx\)
Xác suất (probability density)\(P(a \leq X \leq b) = \displaystyle\int_a^b f(x)\, dx\)
Tốc độ dòng chảy\(Q = \displaystyle\int_{t_1}^{t_2} r(t)\, dt\)
Ví dụ (Example): Xe chuyển động với vận tốc \(v(t) = 3t^2\) (m/s).
Quãng đường từ \(t=0\) đến \(t=2\): \(s = \displaystyle\int_0^2 3t^2\, dt = \left[t^3\right]_0^2 = 8\) (m).
Ứng dụng SAT: tích phân mô hình hóa tổng chi phí, quãng đường, lợi nhuận, xác suất.
